# Website Design Questionnaire

**Random Remi Designs** — tell us about the website you want, in your own words. No design or tech knowledge needed.

**Prefer to click instead of type?** Fill in the [interactive version](index.html). It has a color wheel, theme previews and layout sketches, and you can download your answers when you're done.

## How to fill this in

Answer as much or as little as you like. Anything you leave out, the designer decides for you.

- **Skip freely.** Every question is optional.
- **Tick "Designer's choice"** at the top of any section you're happy to hand over. That way we know you didn't just miss it.
- **Two ways to answer.** Most sections have an *Exactly what I want* box (e.g. "Roboto font, red, white and gray") and a *Describe the feeling* box (e.g. "like feeling safe in a cloud surrounded by soft lights and gentle music"). Use one, both or neither.
- **(additional fee)** marks options that cost extra. Your designer will quote these separately before any work starts.
- **Not sure what a word means?** Check the Glossary at the end. We use everyday words first and the designer's word in brackets.
- **To fill in:** type in the empty table cells and tick the boxes.

## 8. Layout (how things are arranged)

- [ ] Designer's choice — you decide the layout

### The menu bar *(designers call it the "navbar" or "navigation")*

This is the area with links to the parts of your site, like Home, About or Contact. Some people call it the menu, the links or the index.

**Where should it sit?**

- [ ] **Across the top** of the page
- [ ] **Down the side** — the menu stays on the left (or right) and your content shows beside it
- [ ] **Hidden behind a button** (the three-line ☰ "hamburger" icon), on every screen size

**When visitors scroll down, should the menu…**

- [ ] **Stay put** and always be visible *(designers say "sticky" or "fixed")*
- [ ] **Scroll away** with the page *(designers say "static")*
- [ ] **Hide while scrolling down and reappear when scrolling up**

### The top banner *(designers call it the "hero")*

## Glossary: everyday words and designer words

| You might say | Designers say | What it means |
| --- | --- | --- |
| Menu bar, links, index, menu | Navbar / navigation | The area with links to the parts of your site or to other sites |
| Three-line menu button | Hamburger menu | A ☰ button that opens a hidden menu, common on phones |
| Menu that stays on screen | Sticky / fixed navigation | The menu stays visible while you scroll |
| Menu that scrolls away | Static navigation | The menu moves off screen as you scroll |
| Big picture at the top | Hero / hero section | The first large area visitors see |
| Bottom of the page | Footer | The strip at the very bottom of every page |
| Top of the page | Header | The strip at the very top, usually with your logo and menu |
| Look, style, mode | Theme | A complete set of colors, fonts, pictures and icons |
| Lettering style | Font / typeface / font family | A style of letters, including its bold and italic versions |
| Color code | Hex code | A code like #FF0000 that names one exact color |
| Little symbols | Icons | Small pictures like a phone, envelope or shopping cart |
| Works on phones | Responsive design | The site rearranges itself to fit any screen |
| Screen width | Breakpoint | The screen size where the layout changes |
| Website address | Domain | e.g. yourname.com |
| Where the site lives online | Hosting | A company that keeps your site running on the internet |
| Tab icon | Favicon | The tiny picture on a browser tab |
| Link preview | Social share / OG image | The picture shown when someone shares your link |
| Easy for everyone to use | Accessibility | Design that works for people with disabilities or different needs |
| Movement, effects | Animation / transitions | Things that fade, slide or move on the page |
| Mouse-over effect | Hover state | How a button or link changes when the pointer is over it |
| Free to use | Open source / royalty-free / free license | Fonts, images or icons you can use without paying (check each one's rules) |
| Paid to use | Licensed / premium / pro | Materials you pay for the right to use |
